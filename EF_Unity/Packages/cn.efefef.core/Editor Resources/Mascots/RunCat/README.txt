使用说明 (Usage)
----------------
· 本目录素材以 Apache 2.0 许可引入 EFramework，仅用于编辑器界面的吉祥物动画。
· 素材为纯黑单色剪影（RGBA，alpha 承载轮廓），运行时按主题着色，
  因此可以任意替换颜色而无需修改图片本身。
· 若修改或再分发本目录素材，须保留本说明文件与 LICENSE-Apache-2.0.txt。

改动 (Modifications)
-------------------
· 原素材为 32×32 像素、单色剪影、5 帧奔跑循环。
· 本工程使用方式：加载为纹理后按颜色着色（默认暖橘色），按帧率循环播放，
  并在横幅底部做水平位移与掉头镜像，未修改图片像素数据。
